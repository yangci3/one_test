# Phase P1.5 Scene RBAC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gate the Cesium/network module behind RuoYi roles so `net_viewer` gets a static scene+topology, `net_admin` keeps full monitoring, and users with neither see no menu and no 403 spam.

**Architecture:** Move `/cesium` out of `constantRoutes` into `sys_menu` dynamic routes. Seed menu tree + roles `net_admin` / `net_viewer`. Frontend gates UI and `bootstrapGlobalMonitor` on permission strings (never hard-code roleKeys). Clean conflicting hidden menus `2100-2113`.

**Tech Stack:** RuoYi Vue2 + Element UI `v-hasPermi` / `auth.hasPermi`, MySQL `sys_menu`/`sys_role`/`sys_role_menu`, Spring `@PreAuthorize` (existing)

**Spec:** `docs/superpowers/specs/2026-08-06-phase-p1.5-scene-rbac-design.md`

## Global Constraints

- Code checks **permission strings only** (e.g. `scene:probe:query`); never `roleKey === 'net_viewer'`
- `net_viewer`: static scene + topology read-only; no online/offline UI; no probe poll/alerts
- `net_admin` + `admin`: full existing monitor loop
- No global 403 swallow; fix by not calling APIs without perms
- Docs UTF-8 BOM; Git: `D:\gitgit\Git\bin\git.exe`
- Branch: create `feature/phase-p1.5-scene-rbac` from current HEAD
- Do **not** implement P2 history/settings DB in this plan
- Extensibility: new capability packs = new SQL + perms + UI gates (spec section 11)

### Task 3: sceneAuth helper + gate global monitor bootstrap

**Files:**
- Create: `ruoyi-ui/src/utils/scene/sceneAuth.js`
- Modify: `ruoyi-ui/src/main.js`
- Modify: `ruoyi-ui/src/permission.js`
- Modify: `ruoyi-ui/src/utils/scene/globalMonitorRuntime.js`

**Interfaces:**
- Produces:
  - `hasSceneProbeQuery()` -> `auth.hasPermi('scene:probe:query')`
  - `hasSceneProbeEdit()` -> `auth.hasPermi('scene:probe:edit')`
  - `hasSceneMapView()` -> `auth.hasPermi('scene:map:view')`
- `bootstrapGlobalMonitor` / `resumeGlobalMonitorAfterLogin` / `runPoll`: if `!getToken()` or `!hasSceneProbeQuery()`, stop poll and return

- [ ] **Step 1: Create `sceneAuth.js`**

```javascript
import auth from '@/plugins/auth'

export function hasSceneProbeQuery() {
  return auth.hasPermi('scene:probe:query')
}

export function hasSceneProbeEdit() {
  return auth.hasPermi('scene:probe:edit')
}

export function hasSceneMapView() {
  return auth.hasPermi('scene:map:view')
}
```

- [ ] **Step 2: Remove unconditional bootstrap from `main.js`**

Delete:

```javascript
import { bootstrapGlobalMonitor } from '@/utils/scene/globalMonitorRuntime'
bootstrapGlobalMonitor()
```

Reason: at cold start `store.getters.permissions` is empty; polling would 403 for viewers.

- [ ] **Step 3: Start monitor after auth in `permission.js`**

Inside the `GetInfo` success path after `GenerateRoutes` / `next(...)`, add:

```javascript
import { bootstrapGlobalMonitor } from '@/utils/scene/globalMonitorRuntime'
import { hasSceneProbeQuery } from '@/utils/scene/sceneAuth'

if (hasSceneProbeQuery()) {
  bootstrapGlobalMonitor()
}
```

- [ ] **Step 4: Guard runtime**

In `globalMonitorRuntime.js` import `hasSceneProbeQuery` and at the top of `bootstrapGlobalMonitor`, `resumeGlobalMonitorAfterLogin`, and `runPoll`:

```javascript
if (!getToken() || !hasSceneProbeQuery()) {
  stopPersistentAlarm()
  stopPoll()
  return
}
```

(`runPoll` should `return Promise.resolve()` after stop.)

Keep `ruoyi-auth-expired` listener behavior.
